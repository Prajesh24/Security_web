# Starter References (verify each before citing — CU Harvard/APA)

You need **15+**. These are relevant, reputable starting points covering the
controls in this project. **Check the current URL/edition and format in CU
Harvard or CU APA yourself** — do not cite blindly.

## Standards & guidance
1. OWASP (2021) *OWASP Top 10:2021*. Available at: https://owasp.org/Top10/
2. OWASP *Web Security Testing Guide (WSTG)*. https://owasp.org/www-project-web-security-testing-guide/
3. OWASP *Application Security Verification Standard (ASVS)*. https://owasp.org/www-project-application-security-verification-standard/
4. OWASP *Cheat Sheet Series* (Authentication, Password Storage, Session Management, CSRF, Mass Assignment, Access Control). https://cheatsheetseries.owasp.org/
5. NIST (2017/2020) *SP 800-63B: Digital Identity Guidelines — Authentication and Lifecycle Management*. https://pages.nist.gov/800-63-3/sp800-63b.html
6. NIST (2018) *Framework for Improving Critical Infrastructure Cybersecurity (CSF) v1.1*.

## RFCs / technical specs
7. M'Raihi, D. et al. (2011) *RFC 6238: TOTP: Time-Based One-Time Password Algorithm*. https://datatracker.ietf.org/doc/html/rfc6238
8. M'Raihi, D. et al. (2005) *RFC 4226: HOTP: An HMAC-Based One-Time Password Algorithm*.
9. Jones, M., Bradley, J. and Sakimura, N. (2015) *RFC 7519: JSON Web Token (JWT)*. https://datatracker.ietf.org/doc/html/rfc7519
10. Dworkin, M. (2007) *NIST SP 800-38D: Recommendation for Block Cipher Modes of Operation: GCM*. https://csrc.nist.gov/pubs/sp/800/38/d/final
